## Desvios / pendências honestas

- Critério 1 pede VM/Windows **sem Python**: o build e a instalação foram verificados na máquina de desenvolvimento. O pacote é self-contained (`_internal\python312.dll` + todos os DLLs conferidos), mas o teste em VM limpa fica como verificação manual — não havia segunda máquina/VM disponível aqui.
- Critério 5: a chave `Run` é escrita e lida corretamente; o **reboot** propriamente dito não foi executado (reiniciar a máquina de trabalho interromperia a sessão) — o mecanismo é idêntico ao toggle do app testado em M4.
- O pacote carrega `setuptools`/`onnxruntime.transformers`/`bam.*` inteiros via `collect_all` (margem de ~100 MB sob o limite); enxugar fica para o M7 se a revisão quiser.
- SmartScreen: exe sem assinatura → "O Windows protegeu o computador" → "Mais informações" → "Executar assim mesmo" (documentado no 06 — assinatura fora do escopo v1).
