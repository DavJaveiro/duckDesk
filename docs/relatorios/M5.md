# M5 — Modo mascote na barra de tarefas

Branch: `m5-mascot`. Fecha a issue #6.

## O que foi implementado

| Peça | Arquivo | Notas |
|---|---|---|
| Bandeira/retângulo da barra | `src/duckdesk/platform/win_taskbar.py` | `SHAppBarMessage` via ctypes: `get_taskbar_rect` (ABM_GETTASKBARPOS, pixels **físicos**), `taskbar_autohide` (ABM_GETSTATE), `taskbar_edge`. `APPBARDATA` completo (corrigido: passar `None` causava violação de acesso). |
| Topmost + tela cheia | `src/duckdesk/platform/win_topmost.py` | `reassert_topmost` (SetWindowPos TOPMOST|NOACTIVATE) a cada ~1 s; `fullscreen_app_active` via `SHQueryUserNotificationState` (BUSY/D3D_FULL_SCREEN/PRESENTATION_MODE) → mascote esconde e a sim pausa (`_fullscreen_hidden`). |
| Mapa sim↔tela | `src/duckdesk/platform/mascot_map.py` | Qt-free e Win32-free (testável): `Dpi` (físico↔lógico), `compute_band` (barra visível embaixo → chão na borda superior; autohide/topo/lado → degradado p/ borda da área de trabalho), `MascotMapping` (`ppm=S/1,6/H_M`, `H_M=0,1155`, insets 8 px, `clamp_x`, `window_top` com margem `0,04·S`). |
| Câmera/render do mascote | `src/duckdesk/render/mascot.py` | Câmera livre a D=3 m + fovy estreito (~3,5°) ≈ ortográfica (duvidas #8: orto nativa sai preta no mujoco 3.10). Vista lateral (azimuth 270°, +x→direita), `lookat` recentrado a cada quadro junto com a janela (sem tremulação). Máscara alfa: passe seg (geom ids da árvore `trunk_base`, chão/bola/céu fora) atualizado a cada 4 quadros + feather 3×3 ≈ cobertura; saída BGRA pré-multiplicada na resolução física final (MSAA `offsamples=4` substitui supersample manual — duvidas #9). |
| Janela do mascote | `src/duckdesk/ui/mascot_window.py` | `Frameless|Tool|WindowStaysOnTop`, `WA_TranslucentBackground` + `WA_ShowWithoutActivating` + `WS_EX_NOACTIVATE` (clique nunca rouba foco). Pixels alpha=0 atravessam o clique via hit-test nativo de janela em camadas. Sinais: click / duplo-clique / drag start-move-finish / right-click → menu da bandeja. |
| Integração | `src/duckdesk/app.py` | `enter_mascot` (reset em `mascot_last_x` ou 0, yaw aleatório, bola estacionada, autopilot desde IDLE, janela principal esconde), `exit_mascot` (sem reset — pato continua onde está; `last_mode`/`mascot_last_x` persistem), `_tick_mascot` (físico real-time + autopilot + watchdog + soft-clamp na banda), `_mascot_band` (taskbar/workarea/DPI → `MascotMapping`), Ctrl+M e ações da bandeja, timers 1 s/2 s (topmost+fullscreen / retângulo da barra). |
| Interações | `src/duckdesk/app.py` | Clique → 40 % bicar, 30 % sentar/levantar, 15 % cambalhota, 15 % olhar (alvo aleatório de cabeça); duplo-clique → volta ao simulador; arrastar pausa e levanta o pato seguindo o cursor; soltar → reset ereto no x restrito; botão direito → mesmo menu da bandeja. |
| Piloto automático | `brain/autopilot.py` (M2) | Ligado no modo mascote com `x_range` = banda real da barra; todos os pedidos passam pela matriz de regras central (`mgr.request`). |

## Medições de desempenho (60 s, autopilot ligado)

| Config | CPU de 1 núcleo |
|---|---|
| M5 inicial (seg todo quadro, ORT multi-thread) | ~203–210 % |
| ORT 1 thread + supersample 2× | 24,5 % |
| + seg a cada 4 quadros + downsample uint16 | 15,8 % |
| **Final: res nativa + MSAA + feather, 15/12 fps** | **14,4 %** |

## Desvios / dúvidas (ver `duvidas.md` #8–#10)

- **#8**: ortográfica real não renderiza no mujoco 3.10 → aproximação câmera longe+fovy estreito (deriva ~2 %, invisível).
- **#9**: supersample 2× manual substituído por MSAA do GL + feather na máscara (única forma de fechar o alvo de CPU).
- **#10**: clique-através depende do hit-test nativo de janela em camadas (fallback `HTTRANSPARENT` só documentado); cadência 15/12 fps abaixo do teto 30/15 do doc para fechar o alvo de CPU.
- Critério 6 (tela cheia) foi verificado no caminho de código via mock do `SHQueryUserNotificationState`; a demonstração de um app F11 real fica para revisão manual.
